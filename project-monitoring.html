PROJECT 05 / MONITORING

Prometheus & Grafana Monitoring

Implemented infrastructure monitoring using Prometheus and Grafana to collect, visualize and analyze system metrics from a monitored environment.

Prometheus Grafana Node Exporter AWS EC2 Monitoring

01 / OVERVIEW

Project Overview

This project focuses on monitoring infrastructure using Prometheus for metrics collection and Grafana for visualization.

A Node Exporter was used to expose system-level metrics such as CPU, memory and other host information.

Prometheus collects the available metrics and Grafana provides dashboards that make the system information easier to understand.

08 / TROUBLESHOOTING

Challenges & Learning

I learned that monitoring depends on communication between the monitored host, Node Exporter, Prometheus and Grafana.

When metrics are not visible, troubleshooting can involve checking service status, target health, configuration files, ports and network access.

Working with dashboards helped me understand how raw infrastructure metrics can be converted into useful visual information.
