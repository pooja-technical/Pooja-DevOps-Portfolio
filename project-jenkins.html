01 / OVERVIEW

Project Overview

This project focuses on using Jenkins to automate the software delivery process.

Instead of performing each step manually, Jenkins can automatically retrieve source code, build the application, run required checks and deploy the application.

The project helped me understand the role of CI/CD automation in a DevOps workflow.

04 / STAGES

Pipeline Stages

01

Source

Jenkins retrieves the latest application source code from Git.

02

Build

The application is compiled or packaged using the required build commands.

03

Test

Automated checks or tests can be executed before deployment.

04

Deploy

After successful validation, Jenkins performs the deployment step.

05 / PIPELINE AS CODE

Jenkins Pipeline

A Jenkins pipeline can be defined as code using a Jenkinsfile stored with the application source code.

pipeline {

  stages {

    stage('Build') {

      steps {

        echo 'Building application'

      }

    }

    stage('Test') {

      steps {

        echo 'Running tests'

      }

    }

    stage('Deploy') {

      steps {

        echo 'Deploying application'

      }

    }

  }

}

07 / TROUBLESHOOTING

Challenges & Learning

I learned that a CI/CD pipeline consists of multiple stages, and a failure in one stage can prevent later stages from executing.

Troubleshooting therefore involves checking Jenkins console output, build logs, source-code configuration, credentials and environment settings.

This helped me understand how automation tools can make application delivery more consistent and reduce repetitive manual steps.
