PROJECT 04 / INFRASTRUCTURE AS CODE

Terraform AWS Infrastructure

Automated AWS infrastructure provisioning using Terraform, following Infrastructure as Code principles for repeatable and manageable cloud deployments.

Terraform AWS VPC EC2 IaC

01 / OVERVIEW

Project Overview

This project focuses on using Terraform to define and provision AWS infrastructure through configuration files instead of creating resources manually.

The infrastructure is described as code, allowing resources to be created in a repeatable and consistent way.

The project helped me understand the fundamentals of Infrastructure as Code (IaC), Terraform workflow and AWS resource management.

04 / RESOURCES

Terraform Resources

☁

AWS Provider

Connects Terraform with AWS and allows AWS resources to be managed through Terraform.

🌐

VPC

Defines the virtual network in which cloud resources can be deployed.

🔐

Security Group

Controls inbound and outbound traffic for resources such as EC2.

💻

EC2

Provides the compute instance used as part of the infrastructure.

05 / WORKFLOW

Terraform Workflow

01

Write Configuration

Define AWS resources using Terraform configuration files.

02

Terraform Init

Initialize the Terraform working directory and download required providers.

03

Terraform Plan

Preview the infrastructure changes Terraform intends to make.

04

Terraform Apply

Apply the configuration and provision the required AWS resources.

05

Terraform Destroy

Remove the infrastructure created by Terraform when it is no longer required.

06 / COMMANDS

Important Commands

# Initialize Terraform

terraform init

# Validate configuration

terraform validate

# Preview changes

terraform plan

# Create infrastructure

terraform apply

# Remove infrastructure

terraform destroy

07 / TROUBLESHOOTING

Challenges & Learning

One of the important concepts I learned was that Terraform does not simply create resources immediately. It first evaluates the configuration and creates an execution plan.

I also learned the importance of checking AWS credentials, provider configuration, resource dependencies and configuration syntax when troubleshooting Terraform errors.

Understanding the Terraform workflow helped me see how infrastructure changes can be reviewed before they are applied.
