PROJECT 03 / CONTAINERS

Containerized Application

Containerized a multi-service application using Docker and Docker Compose to create a consistent and reproducible application environment.

Docker Docker Compose MongoDB Linux Containers

01 / OVERVIEW

Project Overview

This project focuses on using Docker to package an application and its dependencies into containers.

Docker Compose was used to define and manage multiple services together, making it easier to start and stop the application environment.

A database service using MongoDB was included as part of the multi-container environment.

# Stop Compose services

07 / TROUBLESHOOTING

Challenges & Learning

I learned that a container can run successfully while the application inside it may still be inaccessible if ports are not mapped correctly.

I also learned the importance of checking container logs, container status, environment variables, network configuration and service dependencies when troubleshooting Docker applications.

Working with Docker Compose helped me understand how multiple services can communicate within a containerized application environment.
